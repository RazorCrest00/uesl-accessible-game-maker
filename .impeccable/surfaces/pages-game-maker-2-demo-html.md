# Accessible Game Maker 2.0 concept demo

- **Scope:** `pages/game-maker-2-demo.html` and its fully isolated CSS/JavaScript assets.
- **Mode:** Operate.
- **Audience:** A first-time UESL participant configuring an accessible browser game, with a coach optionally nearby.
- **Job:** Make six decisions, see each decision reflected immediately, test the result, and preserve a safe draft.
- **Primary action:** Continue through the guided path; preview and export the validated configuration at the end.
- **Proof:** A live miniature level changes theme, motion, contrast, control size, speed, and preview state without backend writes.
- **Constraints:** Inherit UESL navy/cyan/purple, Oswald/Inter, and the existing app shell; no production navigation link; no claims of server save or publishing; keyboard, reduced-motion, 200% zoom, and phone layouts remain usable.
- **Direction:** Playtest Workbench. Six numbered work stations share one frame with a persistent miniature stage, so choices and effects are never separated. The memorable moment is the same level repainting and changing motion as the participant tunes it.
- **Structure:** One compact status header, a six-station progress rail, one active decision surface, a persistent live preview, and a validation/action footer. On phones the preview precedes the active decision and the stations become a contained horizontal rail.
- **Unresolved:** The production adapter into inherited game data will be confirmed during issue #4; the demo exports an explicitly labeled versioned preview contract.
